Geass

My self-hosted personal agent. It runs on my homelab on a local open-weight model, talks to me over Telegram and Discord (including live voice channels), and runs 35 scheduled jobs that keep my GRE prep, job search and PhD applications on track. It drafts; it never sends.

Built on the open-source Hermes Agent framework (Nous Research), v0.22.5. Inventory as of November 6, 2026.

A separate research instance on my coding VM hands larger coding tasks to Claude Code and Codex workers, which work on branches and report back in a short RESULT.md.

Voice

Speech runs on a dedicated VM with a GTX 1080: Whisper large-v3-turbo (int8) for transcription and Kokoro-82M for speech, behind an OpenAI-compatible API. Measured warm: 0.44 s to speak a sentence, 0.60 s to transcribe it.

  • Voice notes in Telegram are transcribed, and replies come back as voice bubbles.
  • Live voice channels in Discord: Geass joins, listens, and answers out loud, in a sentence or two. It stays out of the way while I work: it only answers when I say "Geass", within 45 seconds of joining or of its last reply so a back-and-forth flows normally.
  • Interrupting is explicit. Saying "stop", "wait", "hold on" or "I have another question" cuts it off; "wait, what about Friday?" cuts it off and asks the new question. Everything else I say while it's talking is ignored. (Version 1 stopped whenever I made a sound, which cut off five of eight answers.)
  • First measured session: median 2.1 s to think and 6.3 s from my last word to its first word. The gap is mostly reply length, which is what the short-reply mode targets.

Guardrails

  • Drafts only. It never sends an email or submits an application. Reply drafts that would commit me to anything ("yes, I can meet") are rewritten as [YES/NO: …] for me to decide.
  • Scripts for exact work, the model for fuzzy work. Fetching, counting, parsing and file generation are deterministic Python; the model summarizes, drafts and coaches.
  • Résumé facts come only from what I wrote, and I approve them.
  • Allowlisted users only on every chat platform; secrets stay on the machines, never in repos.
  • Prompt regression tests (26 checks) run whenever a prompt, the model or the server version changes.

Limitations

An honest list. Most of these come from running a mid-size local model on home hardware.
  • The model is a coding model. Its prose reads a little mechanical, and left alone it agrees to meetings on my behalf; a second pass catches that. It once claimed to have read PDFs it hadn't, which is why exact steps moved into scripts.
  • 64K context. Tool and skill descriptions alone take 16–21K tokens per turn, so long documents get summarized or chunked, not read whole.
  • Small memory. About 2,200 characters of notes plus a 1,375-character profile of me; anything bigger lives in files it has to look up.
  • No browser, no images, no vision. The model is text-only and those tools aren't set up. Web access is search plus page reading.
  • Voice is good, not instant. Replies are synthesized whole before playback, an interrupt lands about a second after I say it (it waits for me to finish the word), the wake word depends on speech recognition hearing "Geass" correctly, it's English-only in practice, and the voice-channel tuning is a local patch I re-apply after framework updates.
  • It's one homelab. If the speech VM or the LLM box is down, so is that part of Geass; there's no cloud fallback.

What's next

  • Search my notes from chat: my math notes and repos are already indexed for vector search; next is exposing that as a tool.
  • A writing model next to the coding model, adopted only if it beats it on the same regression tests.
  • Streaming speech, so it starts talking after the first sentence instead of the whole reply.
